# Dottogotchi-Heretical-Study-Companion-
A tiny Dottore to support you on your journey through academia...whether you decide to burn it down or not
This project was inspired by the Desktop Companion Robot (https://www.instructables.com/Desktop-Companion-Robot/) and 
its code was used as a base for most  of this project.

HARDWARE
-Seeeed Studio XIAO ESP32-S3
-128x128 pixel OLED 
(These can both be acquired through aliexpress for cheap) 

SOFTWARE
- Pc module is currently built for windows current version all addons that require installation should be listed in the .py      file
- ESP32 runs circuitpy (install guide:https://learn.adafruit.com/circuitpython-with-esp32-quick-start/installing-circuitpython)
  all necessary addons are in the folder Circuitpy_lib, after installing circuitpy just drag them in into the lib folder
- If you want to edit/test files on the ESP32 directly I would recommend installing Thonny 
IMPORTANT: IF YOU HAVE A DIFFERENT SIZED OLED YOU WILL NEED TO INSTALL A DIFFERENT ADAFRUIT_DISPLAYIO FILE AND CHANGE THE CODE

HTML
- Lets you control the animations independently of whatever your computer is doing

DOTTOS
Atm there are 4 working animations in the Dottos folder if you want to edit these just open the bmap in paint. 
All Dottos were created with love in mspaint.

Notes;
While this code was assembled from the original Desktop Companion in combination with a guide on bitmap animations (https://gist.github.com/todbot/1bc6936f273a06667b0e44de5d10cc46#file-animated_gif_player-py), AI was used to troubleshoot problems with the code.
